# Expense Tracker

## Week 2 Python Development Assignment

This project is a command-line Expense Tracker developed using Python.

## Features

- Add daily expenses
- Store amount, category, description, and date
- View all expenses in tabular format
- Filter expenses by category
- Filter expenses by date range
- Generate monthly spending summary
- Calculate total spending
- Calculate percentage spent by category
- Store expense data in CSV format
- Validate amount and date inputs

## Technologies Used

- Python 3.x
- csv module
- datetime module
- collections module
- os module
